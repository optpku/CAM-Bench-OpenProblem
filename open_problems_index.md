## Detailed List

### [凸几何：支撑、面结构与距离配置](01_convex_geometry_support_faces_distance.md)

#### [1. Antipodal Segments and Simplices](01_convex_geometry_support_faces_distance.md#problem-1)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 1.1, Question 1.2
- **Open problem summary:** Bounds the size of pairwise antipodal families of segments and, more generally, $k$-simplices in $\mathbb{R}^d$.

#### [2. Points in an $o$-symmetric Convex Body](01_convex_geometry_support_faces_distance.md#problem-2)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 2.1
- **Open problem summary:** Asks whether every centrally symmetric convex body contains $k$ points at pairwise norm-distance at least $\sqrt{2}$ for $n+2\le k\le 2n$.

#### [3. Faces of a Compact Convex Set](01_convex_geometry_support_faces_distance.md#problem-3)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Conjecture 3.1
- **Open problem summary:** Asks whether every point of a compact convex set can be represented using faces with prescribed dimension bounds.

### [覆盖、体积与极值几何](02_covering_volume_extremal_geometry.md)

#### [1. Planks Covering the Unit Ball](02_covering_volume_extremal_geometry.md#problem-1)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 1.1
- **Open problem summary:** Asks for the maximum volume of the part of the unit ball covered by planks with prescribed widths whose total is less than $2$.

#### [2. Extremal Simplex Intersection in Spherical and Hyperbolic Space](02_covering_volume_extremal_geometry.md#problem-2)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 2.1
- **Open problem summary:** Asks whether the Euclidean extremal simplex-ball intersection theorem remains true in spherical and hyperbolic spaces.

#### [3. Covering a Unit Cube by Smaller Cubes](02_covering_volume_extremal_geometry.md#problem-3)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 3.1
- **Open problem summary:** Asks for the minimum number $q(n)$ of cubes of edge length less than $1$ needed to cover a unit cube in $\mathbb{R}^n$.

#### [4. Volume of the Boolean Quadric Polytope](02_covering_volume_extremal_geometry.md#problem-4)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 4.1
- **Open problem summary:** Asks for a formula or good bounds for the volume of the Boolean Quadric Polytope $P_n$.

### [高维单纯形与三角剖分结构](03_simplices_and_triangulations.md)

#### [1. Triangulations of Perturbed Grid-Squares](03_simplices_and_triangulations.md#problem-1)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 1.1
- **Open problem summary:** Asks whether every triangulation of a perturbed $\sqrt n\times\sqrt n$ grid in $\mathbb{R}^3$ has at most $O(n^{3/2})$ tetrahedra.

#### [2. Incenter on the Euler Line of an $n$-Simplex](03_simplices_and_triangulations.md#problem-2)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 2.1
- **Open problem summary:** Asks for a geometric characterization of $n$-simplices whose incenter lies on the Euler line.

### [图、矩阵与组合凸性参数](04_graph_matrix_convexity_parameters.md)

#### [1. Euclidean, Gram, and $\nu^{=}$ Graph Parameters](04_graph_matrix_convexity_parameters.md#problem-1)

- **Contributor:** Yinyu Ye
- **Open problem labels:** Question 1.1, Question 1.2
- **Open problem summary:** Asks whether $ed(\nabla G)\le ed(G)+1$ and $gd(G)\le \nu^{=}(G)$ hold for all graphs.

### [凸优化、变分分析与算法复杂度](05_convex_optimization_variational_analysis.md)

#### [1. Composite $((L_0,L_1))$-Smooth Optimization](05_convex_optimization_variational_analysis.md#problem-1)

- **Contributor:** Junyu Zhang
- **Open problem labels:** Question 1.1. Tight composite oracle complexity, Question 1.2. Matching lower bound, Question 1.3. Optimal accelerated proximal method
- **Open problem summary:** Asks for the tight proximal first-order oracle complexity for convex composite optimization under $((L_0,L_1))$-smoothness.

#### [2. Silver Stepsize Optimality Conjecture](05_convex_optimization_variational_analysis.md#problem-2)

- **Contributor:** Junyu Zhang
- **Open problem labels:** Question 2.1. Silver stepsize optimality among scalar schedules, Question 2.2. General finite-horizon minimax optimality, Question 2.3. Projected and proximal variants
- **Open problem summary:** Asks whether the silver stepsize schedule is optimal among fixed scalar stepsize schedules for gradient descent.

#### [3. Rockafellar Sum Problem](05_convex_optimization_variational_analysis.md#problem-3)

- **Contributor:** Junyu Zhang
- **Open problem labels:** Question 3.1. Rockafellar Sum Problem in General Banach Spaces
- **Open problem summary:** Asks whether the Rockafellar sum theorem remains true for maximal monotone operators in general Banach spaces.

### [彩色凸性与拓扑组合几何](06_colored_convexity_topological_combinatorics.md)
