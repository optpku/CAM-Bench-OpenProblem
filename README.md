# Open Problems in Mathematics

## About This Project

This repository collects open problems in mathematics. Problems are organized thematically under `open_problems/`. Each entry follows the uniform template described below.

---

## Problem Template

Each problem write-up is divided into the following sections. Sections that are not applicable to a particular problem may be omitted.

**1. Problem Background**
Motivation and historical context. Explains where the problem comes from, why it is interesting, and how it fits into the broader literature.

**2. Definitions and Conventions**
Precise definitions of every non-standard term appearing in the problem statement. Includes source citations for each definition where appropriate.

**3. Open Problems**
The explicit open question(s) or conjecture(s), stated as precisely as possible.

**4. Known Results**
Theorems and partial results that are directly relevant to the open problem — e.g., special cases that have been solved, related bounds, or equivalent reformulations. Each result includes a source citation.

**5. References**
Full bibliographic entries for all works cited in the write-up.
